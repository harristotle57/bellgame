# Student folders

Each student works in their own folder here.

1. Copy the template: `cp -r students/_template students/<your-name>`
2. Open `students/<your-name>/starter.py` in Spyder, VS Code, or Jupyter.
3. Work on your own git branch (see `CONTRIBUTING.md` at the top of the repo).

Your folder is yours: add as many scripts as you like. If you write a function
that everyone could use, see CONTRIBUTING.md for how to move it into `src/bellgame/`.
