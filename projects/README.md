# Projects

A project is a study that builds towards a conclusion: a question, the
simulations that answer it, and the plots, notes, configurations or slides that
come out of it. Each project gets its own folder, so all of that can live
together, and the research group can see and build on each other's work.

(A single self-contained script that shows how to use part of bellgame belongs
in `examples/` instead.)

1. Copy the template: `cp -r projects/_template projects/<project-name>`
2. Open `projects/<project-name>/starter.py` in Spyder, VS Code, or Jupyter.
3. Work on your own git branch (see `CONTRIBUTING.md` at the top of the repo).

Add whatever the project needs: more scripts, data, figures, LaTeX. If you write
a function that everyone could use, see `CONTRIBUTING.md` for how to move it
into `src/bellgame/`.
